# 🍺 homebrew-tap

Homebrew tap for [**srikalachallagundla32-cloud**](https://github.com/srikalachallagundla32-cloud) projects.

Formulae and casks in this repo are generated automatically by
[GoReleaser](https://goreleaser.com) on each release — **don't edit them by hand.**

## Install

```bash
brew install srikalachallagundla32-cloud/tap/finops-guard
```

or, equivalently:

```bash
brew tap srikalachallagundla32-cloud/tap
brew install finops-guard
```

## Packages

| Package | Description |
|---------|-------------|
| [`finops-guard`](https://github.com/srikalachallagundla32-cloud/finops-guard) | Shift-left cost protection for cloud & LLM API calls — static loop-cost detection, an animated TUI, and GitHub PR cost cards. |

## Update / uninstall

```bash
brew update && brew upgrade finops-guard
brew uninstall finops-guard
```
